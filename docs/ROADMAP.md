# KURO Engineering Roadmap

## v0.1-alpha (current)
- Loopback-only policy, single GET, basic headers checks, JSON report, tests.

## v0.1-beta
- Origin/path policy tests, shared request budget, bounded crawler, structured evidence, deterministic finding fingerprints.

## v0.2
- Manual request replay, test identities, role matrices, authorization assertions, safe fixture tests.

## v0.3
- Controlled lab-only XSS/injection/path-handling test modules, differential validation, false-positive suites.

## v0.4
- HTML reports, retesting, redacted evidence integrity manifest, remediation templates.

## v0.5
- CI integrations, benchmarks, cancellation/recovery, coverage summaries.

## v1.0
- Stable interfaces, comprehensive threat model, reproducible builds, independently reviewed scope enforcement.
